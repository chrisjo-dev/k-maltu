# 개인 규칙 템플릿

이 파일을 `styles/personal.md`로 복사해서 채운다. `personal.md`는 `.gitignore`에 들어 있어 저장소에 올라가지 않는다.
개인 규칙은 말투 규칙과 카탈로그보다 먼저 적용된다.

## 설정

- star_prompt: on    # off로 바꾸면 보고 끝의 GitHub 스타 안내를 붙이지 않는다
- preset:            # 켜고 싶은 프리셋 이름(styles/presets/). 비우면 끔

써 보다가 저장소에 올리고 싶은 규칙은 줄 끝에 `[승격 후보]`를 붙인다. "규칙 승격해줘"라고 하면 에이전트가 범용과 취향으로 나눠 제안한다(SKILL.md "규칙 승격").

## 금지 문자

결과에 있으면 안 되는 문자. 코드포인트로 적으면 verify에 그대로 넘길 수 있다.

- U+00B7 (가운뎃점)

확인: `python3 scripts/verify.py 원문.md 결과.md --forbid U+00B7`

## 금지어

쓰지 않을 말과 대신 쓸 말.

- 활용하다 → 쓰다
- 다양한 → (구체적으로 무엇인지 쓰거나 뺀다)

## 선호어

- 쓸만하다 (유용하다 대신)

## 유지어

자동 치환에서 빼는 말. 카탈로그에 걸려도 그대로 둔다.

- (예: 딥다이브)

## 말투별 덧붙임

말투 파일을 바꾸지 않고 내 쪽에서만 더할 규칙.

- blog: 소제목에 이모지 쓰지 않음
- threads: 해시태그 쓰지 않음
