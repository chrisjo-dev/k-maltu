# 프리셋: 켜서 쓰는 취향 규칙

프리셋은 "모두에게 맞지는 않지만 누군가에게는 늘 원하는" 문체 취향 묶음이다. 기본값으로는 꺼져 있고, 원하는 사람만 켠다.

## 켜는 방법

`styles/personal.md`의 설정에 적는다.

```
- preset: 이름        # styles/presets/이름.md 를 적용
```

여러 개는 쉼표로 적는다(`preset: a, b`). 앞에 적은 것이 우선한다.

## 우선순위

`styles/personal.md` > 프리셋 > `registers/<말투>.md` > `styles/base/` > 수정량 상한

## 프리셋 만들기

1. `_template.md`를 복사해 `<이름>.md`로 만든다. 이름은 영문 소문자와 하이픈.
2. 규칙마다 "무엇을, 왜, 예외"를 적는다. 시험지(`bench/items/`) 문장을 예시로 쓰지 않는다.
3. 프리셋은 실측 없이 추가할 수 있다(켜는 사람만 영향받음). 다만 숫자, 고유명사, 링크 보존 같은 공통 원칙을 어기는 규칙은 넣지 않는다.

## 범용 규칙과 구분

모두에게 좋은 규칙(예: "~를 통해"를 문맥에 맞게 "~로")은 프리셋이 아니라 `styles/base/`나 `registers/`로 올린다. 이 경우는 `bench/`로 실측해서 기존보다 나빠지지 않을 때만 반영한다(SKILL.md의 "규칙 승격" 참고).
